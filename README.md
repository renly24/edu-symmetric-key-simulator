# 共通鍵暗号方式のしくみ（教育用）

暗号化と復号に同じ鍵を使う **共通鍵暗号方式** のしくみを、自分で暗号化・復号しながら学ぶ教育用の Web アプリです。

## 学べること

教科書（情報 I「安全な通信」）の共通鍵暗号方式の範囲を、全4章・16枚のスライドで、自分で操作しながら学びます。ほとんどのスライドに「🎯 やってみよう」（操作の課題）があり、クリアすると次のスライドへ進めます。

1. **情報の暗号化**：通信が盗聴されるとどうなるか（メッセージを送る・盗聴者になってのぞき見る）、平文・暗号文・暗号化・復号・鍵ということば
2. **共通鍵暗号方式**：鍵を使って暗号化・復号する体験（例として文字をずらす暗号を使う）、暗号化と復号に同じ鍵（共通鍵）を使うこと、対称鍵暗号とも呼ばれること、送受信の手順
3. **共通鍵暗号方式の課題**：共通鍵を安全に渡す方法の問題、送る相手ごとに鍵が必要で、人数が増えると鍵の管理が大変になること
4. **まとめ**：長所（処理が速い）と課題の仕分け、代表的な暗号化アルゴリズム AES（無線 LAN の WPA2・WPA3）、8問のまとめテスト（採点・見直し付き）

### さわって確かめる（いろいろな操作）

| 操作 | スライド |
| --- | --- |
| **ドラッグ** | メッセージ・暗号文・鍵の札を Aさんから Bさんへ送る（途中で盗聴者がコピーする）／ことばのカードを図に入れる／人と人の間に線を引いて鍵を作る／特徴のカードを「長所」「課題」に仕分ける |
| **カーソル移動** | 盗聴者になって、通信路の上で虫めがねを動かし、流れているメッセージをのぞき見る（暗号なし・暗号ありの2回） |
| **マウスホイール** | 暗号円盤を回して鍵を変える（鍵で暗号化するしくみ・違う鍵での復号） |
| **ダブルクリック** | ずらし表の文字をダブルクリックして、暗号化・復号の答えを入力する |
| **クリック・タップ** | 手順を並べる／問題に答える |

ドラッグの操作は、タップで選んでからタップで置く方法でもできます（スマホ・タブレット向け）。円盤には「鍵 −1」「鍵 ＋1」のボタンもあります。

### 問題の種類

- **予想問題**：操作の前に「どうなると思う？」と考える問題。答えるまで次のスライドへ進めません。正解の位置は問題ごとにばらばらです
- **体験問題**：ことばを図に入れる、手で暗号化・復号する、手順を並べる、鍵の線を引く、特徴を仕分けるなど、自分で操作する問題
- **確認問題**：最後のまとめテスト。まとめテストの結果画面はスクリーンショットで提出する想定です（結果はサーバに保存されません）

パワーポイントのスライドのように、画面下の「前へ」「次へ」ボタンやスライドのクリック・タップで1枚ずつ進めます（← → ・スペースキーでも操作できます。問題や「やってみよう」のあるスライドではクリックで進みません）。

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-symmetric-key-simulator/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-symmetric-key-simulator/ （`.github/workflows/deploy-ftp.yml`）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります。
