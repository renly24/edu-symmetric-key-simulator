# 共通鍵暗号方式のしくみ（教育用）

暗号化と復号に同じ鍵を使う **共通鍵暗号方式** のしくみを、自分で暗号を作ったり解読したりしながら学ぶ教育用の Web アプリです。

## 学べること

全5章・21枚のスライドで、問題を解きながら進めます。

1. **暗号ってなに？**：通信が盗聴されるとどうなるか、平文・暗号文・鍵・暗号化・復号ということば
2. **共通鍵で暗号化する**：文字をずらすシーザー暗号で、暗号化と復号を手で体験。違う鍵では戻せないこと、共通鍵暗号方式（秘密鍵暗号方式）とは何か
3. **鍵の強さ**：25 通りしか鍵がないシーザー暗号を総当たりで解読。コンピュータの暗号（ビットの XOR）と、鍵の長さと総当たりにかかる時間
4. **鍵の受け渡し**：鍵を通信路で送ると盗まれる「鍵配送問題」と、人数が増えると鍵が n ×（n − 1）÷ 2 個必要になること
5. **まとめ**：よいところ・困るところ、手順の並べ替え、8問のまとめテスト（採点・見直し付き）

### 見て・さわって確かめる

- **送受信の図**：Aさん → Bさんの通信路を、平文・暗号文・鍵が流れ、盗聴者がコピーする様子を「1つ進める」で1ステップずつ見られます（暗号なし・共通鍵で暗号化・鍵も送ってしまう、の3場面）
- **ずらし表**：鍵（ずらす数）をつまみで変えると、平文の段と暗号文の段の対応が変わります
- **手で暗号化・復号**：表を見ながら1文字ずつ入力して答え合わせ。入力する欄を選ぶと、表の探す文字が光ります
- **違う鍵で復号**：鍵を変えると、意味のある言葉に戻るのは同じ鍵のときだけだと分かります
- **総当たり**：盗聴者になって、鍵を1つずつ試して暗号文を解読します
- **ビットの暗号（XOR）**：鍵のビットをタップして変えても、同じ鍵で計算し直すと必ず平文に戻ります
- **鍵の長さ**：鍵のビット数を変えると、鍵の数と、1秒に1兆個試せるコンピュータで全部試す時間が変わります
- **人数と鍵の数**：人数を変えると、必要な鍵（線）の数が増えていく様子が見られます

### 問題の種類

- **予想問題**：操作やアニメーションの前に「どうなると思う？」と考える問題。答えるまで次のスライドへ進めません
- **体験問題**：手で暗号化・復号する、総当たりで解読する、手順を並べるなど、自分で操作する問題
- **確認問題**：章の終わりと最後のまとめテスト。まとめテストの結果画面はスクリーンショットで提出する想定です（結果はサーバに保存されません）

パワーポイントのスライドのように、画面下の「前へ」「次へ」ボタンやスライドのクリック・タップで1枚ずつ進めます（← → ・スペースキーでも操作できます。問題のスライドではクリックで進みません）。

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-symmetric-key-simulator/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-symmetric-key-simulator/ （`.github/workflows/deploy-ftp.yml`）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります。
