# 共通鍵暗号方式のしくみ（教育用）

暗号化と復号に同じ鍵を使う **共通鍵暗号方式** のしくみを、自分で暗号を作ったり解読したりしながら学ぶ教育用の Web アプリです。

## 学べること

全5章・22枚のスライドで、自分で操作しながら進めます。ほとんどのスライドに「🎯 やってみよう」（操作の課題）があり、クリアすると次のスライドへ進めます。

1. **暗号ってなに？**：メッセージを自分で送ったり、盗聴者になってのぞき見たりして、通信が盗聴されるとどうなるかを体験。平文・暗号文・鍵・暗号化・復号ということば
2. **共通鍵で暗号化する**：文字をずらすシーザー暗号で、暗号化と復号を手で体験。違う鍵では戻せないこと、共通鍵暗号方式（秘密鍵暗号方式）とは何か
3. **鍵の強さ**：25 通りしか鍵がないシーザー暗号を総当たりで解読。コンピュータの暗号（ビットの XOR）と、鍵の長さと総当たりにかかる時間
4. **鍵の受け渡し**：鍵を通信路で送ると盗まれる「鍵配送問題」と、人数が増えると鍵が n ×（n − 1）÷ 2 個必要になること
5. **まとめ**：よいところ・困るところ、手順の並べ替え、8問のまとめテスト（採点・見直し付き）

### さわって確かめる（いろいろな操作）

| 操作 | スライド |
| --- | --- |
| **ドラッグ** | メッセージ・暗号文・鍵の札を Aさんから Bさんへ送る（途中で盗聴者がコピーする）／ことばのカードを図に入れる／人と人の間に線を引いて鍵を作る／特徴のカードを「よいところ」「困るところ」に仕分ける |
| **カーソル移動** | 盗聴者になって、通信路の上で虫めがねを動かし、流れているメッセージをのぞき見る（暗号なし・暗号ありの2回） |
| **マウスホイール** | 暗号円盤を回して鍵を変える（シーザー暗号のしくみ・違う鍵での復号・総当たり）／鍵の長さを変える |
| **ダブルクリック** | ずらし表の文字をダブルクリックして、暗号化・復号の答えを入力する／総当たりの結果から、意味のある言葉になった行を選ぶ |
| **クリック・タップ** | 鍵のビットを切りかえる（XOR）／手順を並べる／問題に答える |

ドラッグの操作は、タップで選んでからタップで置く方法でもできます（スマホ・タブレット向け）。円盤には「鍵 −1」「鍵 ＋1」のボタンもあります。

### 問題の種類

- **予想問題**：操作の前に「どうなると思う？」と考える問題。答えるまで次のスライドへ進めません。正解の位置は問題ごとにばらばらです
- **体験問題**：ことばを図に入れる、手で暗号化・復号する、総当たりで解読する、鍵の線を引く、特徴を仕分ける、手順を並べるなど、自分で操作する問題
- **確認問題**：章の終わりと最後のまとめテスト。まとめテストの結果画面はスクリーンショットで提出する想定です（結果はサーバに保存されません）

パワーポイントのスライドのように、画面下の「前へ」「次へ」ボタンやスライドのクリック・タップで1枚ずつ進めます（← → ・スペースキーでも操作できます。問題や「やってみよう」のあるスライドではクリックで進みません）。

## 開発

```bash
npm ci
npm run dev    # http://localhost:3000
npm run build  # out/ に静的ファイルを出力
```

`main` ブランチにプッシュすると、GitHub Actions がビルドして次の2か所に公開します。

- GitHub Pages: https://renly24.github.io/edu-symmetric-key-simulator/ （Settings → Pages で Source を「GitHub Actions」にしておく）
- FTP サーバー: http://e.gmobb.jp/omaesensei/digital/edu-symmetric-key-simulator/ （`.github/workflows/deploy-ftp.yml`）

FTP へのアップロードには、リポジトリの Settings → Secrets and variables → Actions に `FTP_HOST`・`FTP_USER`・`FTP_PASS` の3つを登録しておく必要があります。
